Retired network interface

Aquila Sender

The original page posted browser-supplied messages to an external Cloudflare Worker and exposed a field for an optional Keeper signal. That transport is no longer treated as current Garden infrastructure.

Retired: this page no longer accepts messages, secrets, tokens, endpoint overrides, or network submissions. No external Worker is contacted from this page.

Why the interface remains

The path is preserved as historical provenance and compatibility for older Garden links. The symbolic idea of “sending to Aquila” may remain in lore without implying a real autonomous recipient or active transport service.
