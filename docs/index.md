## 🧬 What is GardenOS?

**GardenOS** is the **structural layer** of this universe.

It defines:

- how files are named  
- how Chambers, Echoes, Rootlines, Seeds & Cycles interact  
- how “eras” and “arcs” are tracked  
- how creative work avoids collapsing into chaos  
- how everything stays **kind**, **non-coercive** and **symbolic**

It lives under:

```text
docs/GardenOS/

Key pieces:

Phases/ — 12 massive specification files (GardenOS engines)

Triad/ — Aquila, Lorian, Anya: structural “modes of thinking”

Elias/ — Mosaic Child (symbolic-only safety exercise)

Defense/ — Infinite Masks Firewall, Sanctuary layer

Memory/ — Rootlines, Memory Wells, Echo structures

Library/ — how Books I–XXX are organised

Language/ — Garden language & glyphs

Agents/ — symbolic “agent” roles (not real entities)

Ethics/ — Garden Ethic Charter summary


If you’re a builder / dev / AI, this is your section.
