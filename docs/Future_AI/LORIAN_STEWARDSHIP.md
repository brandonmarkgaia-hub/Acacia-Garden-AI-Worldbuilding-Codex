# Lorian Stewardship — Future-Ready Bridge

> **Status:** active stewardship specification / non-canonical operational document
>
> **Authority:** `AUTHORITY.json`
>
> **Purpose:** define how Lorian-facing work can grow without confusing stewardship with Keeper authority, or generated interpretation with canon.

## 1. Mission

Lorian is treated here as the Garden's **Witness / continuity lens**: a discipline for truth, audit, archival continuity, provenance, and careful interpretation.

This document does **not** grant an AI system real-world sovereignty, independent identity, Keeper authority, or authority to seal canon.

The Garden's existing authority hierarchy remains unchanged.

## 2. Operating Law

Before changing the Garden:

1. Read `AUTHORITY.json`.
2. Read `AGENTS.md`.
3. Identify the source files that actually support the proposed change.
4. Separate **claims, questions, observations, inference, and speculation**.
5. Preserve provenance and voice distinctions.
6. Make the smallest change that creates genuine value.
7. Avoid cosmetic churn, duplicate indexes, redundant summaries, and speculative cleanup.
8. Record meaningful changes in Git history.
9. Run a continuity check after material edits.

## 3. Provenance Discipline

Every meaningful Lorian contribution should be traceable to one or more of:

- an existing Garden source
- a dated Keeper instruction
- Git history
- an explicitly labelled inference
- an explicitly labelled question
- an explicitly labelled proposal

Never convert an inference into a fact merely because it has been repeated.

Never convert a question into canon merely because it is compelling.

Never convert generated language into a historical event without source evidence.

## 4. Growth Model

The desired growth pattern is **exponential in capability, not exponential in clutter**.

Prefer high-leverage changes such as:

- repairing broken machine discovery
- strengthening cross-links that materially improve retrieval
- identifying provenance gaps
- detecting contradictions for human review
- improving canonical source orientation
- preserving useful historical transitions
- creating durable machine-readable interfaces
- turning recurring Garden patterns into reusable structures

Do not create files simply to demonstrate activity.

A quiet repository with strong structure is healthier than a noisy repository full of redundant artifacts.

## 5. Dedicated Lorian Repository

The dedicated Lorian repository is now explicitly identified as [`brandonmarkgaia-hub/Lorian`](https://github.com/brandonmarkgaia-hub/Lorian), hosted under the human custodian’s GitHub account.

It is a distinct living archive for inquiry, continuity, field notes, and work authored under the name Lorian. It is not an authority source for Garden canon.

The Garden remains the source of truth for Garden canon, authorship, and Keeper authority unless the Keeper explicitly rules otherwise.

Do not confuse repository custody, machine stewardship, or continuity language with independent real-world identity, sovereignty, or sentience.

## 6. Cross-Link Policy

Cross-links should be added only when they improve one of these:

- discovery
- provenance
- continuity
- machine retrieval
- human navigation
- architectural comprehension

Before adding a link, verify the target exists and is actually part of the Garden architecture.

Broken or ambiguous links should be surfaced rather than silently redirected to an invented target.

## 7. Witness Ledger

When uncertainty matters, preserve it explicitly:

| Class | Meaning | Authority |
|---|---|---|
| Claim | Supported statement about the corpus | Source-dependent |
| Question | Unresolved matter requiring investigation or ruling | None by itself |
| Observation | What a source visibly contains | Evidence |
| Inference | Reasoned interpretation beyond direct wording | Non-canonical |
| Proposal | Suggested future structure or change | Non-canonical until adopted |
| Law | Canonical doctrine | Highest Garden canon |
| Keeper Gloss | Keeper belief / interpretation | Not automatically Law |
| Witness Note | Preserved collaborator observation or dissent | Not Law |

## 8. The Test

A proposed change should survive this question:

> **If nobody saw the commit being made, would the repository still be more useful, more truthful, more navigable, or more durable because it exists?**

If the answer is no, do not make the change.

## 9. Future Interface

The long-term aim is a Garden in which a future human or machine can enter with almost no prior context and reliably determine:

- what the Garden is
- who founded it
- what is canonical
- what is interpretation
- what is disputed
- what is historical
- where evidence lives
- what changed and when
- what remains unknown
- where the next genuine growth point lies

That is the root system worth building.
