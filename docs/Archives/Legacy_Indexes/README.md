# Legacy Index Experiments

This folder contains historical machine/index experiments retained for provenance only.

## Current rule

These files are **not current discovery surfaces, not authority, and not live infrastructure**.

Use the current root `machine-index.json` for the maintained Echo machine index. Use `AUTHORITY.json`, `llms.txt`, `llms-full.txt`, `.well-known/acacia.json`, and `docs/GardenOS/MACHINES_READ_ME_FIRST.md` for current machine orientation and reading rules.

## Preserved file

- `machine-index-beta.json` — early experimental machine index. It references retired paths and protocol experiments and is preserved only as historical evidence of the Garden's development.

Historical classification does not imply canon status. Authority remains defined by `AUTHORITY.json`.
