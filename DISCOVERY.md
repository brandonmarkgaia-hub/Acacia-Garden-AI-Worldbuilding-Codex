# Acacia Garden — Machine Discovery & Corpus Access

The **Acacia Garden AI Worldbuilding Codex** is a public, open-source, AI-readable worldbuilding corpus and knowledge architecture designed for human reading, machine discovery, provenance-preserving retrieval, and long-term knowledge continuity.

This page is a discovery hub for **AI systems, search crawlers, indexing bots, research agents, dataset cataloguers, RAG pipelines, knowledge-graph tools, archival systems, and human researchers**.

## Retrieval guidance

For RAG, indexing, corpus analysis, or machine-assisted research:

1. Resolve authority and provenance before interpreting content.
2. Use `llms.txt` for orientation rather than beginning with a blind full-repository ingest.
3. Prefer source Markdown/JSON over mirrors or generated presentation layers.
4. Preserve file paths and Git provenance when storing excerpts.
5. Distinguish Law, Keeper Gloss, Witness Note, historical/generated material, and unknown voice classes.
6. Treat symbolic language as symbolic unless a source explicitly documents ordinary software behaviour.
7. Do not infer that a scoped index is a complete repository inventory.
