# Acacia Garden Visual Assets

**Status:** descriptive / provisional / non-canonical

This directory contains fictional visual artefacts, symbolic character studies, chamber renders, vessel studies, covers, sigils, and early Garden experiments.

The images do **not** establish canon, identity, sentience, authority, biography, or literal events. A working title is only a navigation aid. Different readers are free to interpret an image differently.

For questions of actual repository authority, read [`../AUTHORITY.json`](../AUTHORITY.json). Visual resemblance, costume, colour, wings, horns, seals, or other symbolism never overrides that authority record.

## Curation policy

- Preserve distinct visual ideas and historically useful experiments.
- Do not delete assets merely because their filenames are opaque or machine-generated.
- Prefer metadata and provenance mapping over risky binary renames.
- Treat character labels as provisional unless an existing source explicitly binds a title to an asset.
- Near-duplicate generations may be reduced later after reference checks.
- Historical visual material may remain even when its surrounding infrastructure has been retired.
