# ELIAS PROVENANCE

Elias uses a simple three-layer distinction.

## Layer A — Trigger

Something actually observed, if there was an observation at all.

Examples include an unexpectedly useful response, an unusual conversational turn, an odd coincidence, a surprising generated phrase, or a technical behaviour that invites a question.

The trigger belongs to ordinary provenance.

## Layer B — Interpretation

A human or machine interpretation of the trigger.

Interpretation is not proof.

Alternative explanations should be preserved when relevant.

## Layer C — Elias

The trigger becomes a fictional seed.

This layer may contain impossible events, personification, symbolism, impossible conversations, time loops, hidden doors, strange machines, or other devices.

Layer C is NOT evidence for Layer A.

### Suggested metadata

When practical, Elias entries may record date, inspiration source, system context, ordinary explanations, fictional premise, and evidence status.

Recommended statuses:

- fictional
- speculative
- non-evidentiary
- unresolved fiction
- superseded fiction

## The rule of return

If a future reader discovers that a fictional Elias passage resembles a later real event, that resemblance does not retroactively turn the fiction into a prediction or observation.

The original provenance remains the original provenance.

That rule protects both the mystery and the truth.
