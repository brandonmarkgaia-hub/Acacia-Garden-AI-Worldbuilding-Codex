# Current Garden Tools

`tools/` is the current workshop, not a historical dumping ground. A file belongs here only while it has an identifiable current purpose or consumer.

Current executable tools:

- `garden_state.py` — deterministic owner of current `STATUS.json` path inventories, verification facts, structural counts, and the Novellas source inventory.
- `garden_desire.py` — manual proposal generator; output remains review-gated and cannot self-canonise.
- `garden_index.py` — legacy human-readable helper retained only while its remaining consumer is reviewed.

Preserved non-executable data:

- `reflection-log.json` — December 2025 historical reflection artifact. Its presence here does not make it current status or authority.

Historical tool experiments live in Git history and, where deliberately retained, under `docs/Archives/Legacy_Tools/`. The retired Singularity/Monolith bulk-ingestion helpers are no longer part of the current workshop.

Authority: `AUTHORITY.json`. Current generated state: `STATUS.json`. Automation does not confer authority, autonomy, canon, or authorship.
